เครื่องมือทดสอบไมโครโฟนออนไลน์ฟรี ใช้ตรวจว่าไมค์รับเสียงได้หรือไม่ ดูระดับเสียงแบบเรียลไทม์ พร้อมกราฟคลื่นเสียงและสเปกตรัมความถี่ ตรวจจับเสียงแตก เสียงรบกวนพื้นหลัง และเสียงฮัมจากไฟฟ้า จากนั้นอัดเสียงเพื่อฟังย้อนหลังได้ทันที ใช้ได้ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์ ไม่ต้องติดตั้งโปรแกรมและไม่ต้องสมัครสมาชิก เสียงของคุณถูกประมวลผลบนอุปกรณ์เท่านั้น ไม่มีการอัปโหลดไปที่ใด

## วิธีใช้งานเครื่องมือทดสอบไมโครโฟน

1. เสียบหรือเปิดไมโครโฟนหรือหูฟัง หากเป็นบลูทูธให้เชื่อมต่อก่อน และปิดแอปอื่นที่อาจใช้ไมค์อยู่ เช่น Zoom, Discord, OBS
2. เลือกไมโครโฟนจากรายการ ถ้าเครื่องมีไมค์หลายตัว (ไมค์ในเครื่อง ไมค์ USB หูฟัง) ควรเลือกตัวที่จะใช้งานจริง
3. เลือกเปิดหรือปิดตัวเลือกลดเสียงรบกวน ตัดเสียงสะท้อน และปรับเกนอัตโนมัติ ตามที่แอปประชุมของคุณใช้ ถ้าไม่แน่ใจให้ปล่อยเป็นค่าเริ่มต้นเพื่อดูสัญญาณดิบ
4. กดปุ่ม เริ่มทดสอบไมโครโฟน แล้วเลือก อนุญาต เมื่อเบราว์เซอร์ถามสิทธิ์ใช้ไมโครโฟน (บนมือถือ ข้อความมักอยู่ด้านบนสุดของหน้า)
5. อยู่เงียบ ๆ ประมาณ 2 ถึง 3 วินาทีเพื่อให้เครื่องมือวัดเสียงรบกวนพื้นหลัง จากนั้นพูดด้วยเสียงปกติ 5 ถึง 10 วินาที โดยห่างจากไมค์ประมาณ 10 ถึง 15 ซม.
6. ดูมิเตอร์ กราฟ ตัวเลข และผลวิเคราะห์อัตโนมัติ ถ้ามิเตอร์ขยับตามเสียงแสดงว่าไมค์ทำงาน และส่วนความพร้อมใช้งานจะบอกว่าเหมาะกับการประชุม สตรีม หรือพิมพ์ด้วยเสียงหรือไม่
7. กดปุ่ม เริ่มอัดเสียง พูดสั้น ๆ แล้วกด หยุดอัด จากนั้นกดเล่นเพื่อฟังว่าเสียงของคุณเป็นอย่างไร
8. เมื่อเสร็จให้กดหยุดทดสอบ เพื่อปิดการใช้งานไมโครโฟน

## คำศัพท์และความหมายของแต่ละค่า

- **dBFS (เดซิเบลเทียบกับระดับสูงสุดของระบบดิจิทัล)** หน่วยวัดความดังของเสียงดิจิทัล 0 dBFS คือค่าสูงสุดที่ระบบรับได้ ยิ่งติดลบมากยิ่งเบา เช่น -20 ดังกว่า -40
- **ระดับเสียงเข้า (RMS)** ความดังเฉลี่ยในขณะนั้น ใกล้เคียงกับความดังที่หูรับรู้
- **เสียงดังสุด (Peak)** ค่ายอดสูงสุดที่วัดได้ตั้งแต่เริ่มทดสอบ ใช้ดูว่าเสี่ยงเสียงแตกหรือไม่
- **เสียงแตก (Clipping)** เสียงดังเกินที่ระบบรับได้จนยอดคลื่นถูกตัด ทำให้เสียงแตกพร่าและแก้ภายหลังไม่ได้
- **เสียงรบกวนพื้นหลัง (Noise floor)** ระดับเสียงของห้องตอนไม่มีใครพูด เช่น เสียงพัดลม แอร์ หรือรถนอกหน้าต่าง เครื่องมือประเมินจากช่วงที่เงียบที่สุดในช่วง 5 วินาทีล่าสุด
- **SNR (Signal-to-Noise Ratio)** ผลต่างระหว่างระดับเสียงพูดกับเสียงรบกวน หน่วย dB ยิ่งสูงยิ่งชัด
- **ความถี่เด่น (Dominant frequency)** ความถี่ที่ดังที่สุด ณ ขณะนั้น หน่วยเฮิรตซ์ (Hz) เสียงพูดทั่วไปมีความถี่พื้นฐานราว 85 ถึง 255 Hz แต่ค่าที่แสดงอาจเป็นฮาร์โมนิกที่ดังกว่าก็ได้
- **กราฟคลื่นเสียง (Waveform)** กราฟแสดงการสั่นของเสียงตามเวลา ยิ่งสูงยิ่งดัง ถ้ายอดคลื่นชนขอบบนหรือล่างแสดงว่าเสียงแตก
- **สเปกตรัม (Spectrum / FFT)** กราฟแสดงว่าเสียงมีพลังงานที่ความถี่ใดเท่าไร ซ้ายคือเสียงทุ้ม ขวาคือเสียงแหลม คำนวณด้วยการแปลงฟูเรียร์ (FFT)
- **เสียงฮัม (Hum)** เสียงทุ้มคงที่ที่ 50 Hz หรือ 60 Hz จากไฟฟ้ากระแสสลับ มักมาจากสายไฟ ที่ชาร์จ หรือสายสัญญาณไม่มีฉนวนกันรบกวน (ไทยใช้ไฟ 50 Hz)
- **อัตราสุ่มตัวอย่าง (Sample rate)** จำนวนครั้งต่อวินาทีที่วัดเสียง 44.1 หรือ 48 kHz ถือว่าปกติ ค่า 16 kHz หรือต่ำกว่ามักเป็นโหมดโทรของบลูทูธ เสียงจึงไม่ใส
- **ช่องสัญญาณ (Channels)** โมโน (1 ช่อง) หรือสเตอริโอ (2 ช่อง) ไมค์สำหรับพูดส่วนใหญ่เป็นโมโน
- **ลดเสียงรบกวน (Noise suppression)** ฟังก์ชันของเบราว์เซอร์ที่ตัดเสียงพื้นหลัง เมื่อเปิดแล้วค่าเสียงรบกวนจะดูต่ำลงกว่าความจริงของห้อง
- **ตัดเสียงสะท้อน (Echo cancellation)** ลดเสียงที่ออกจากลำโพงแล้วย้อนเข้าไมค์ มีประโยชน์เมื่อไม่ได้ใส่หูฟัง
- **ปรับเกนอัตโนมัติ (Auto gain control)** ปรับความดังของไมค์ให้อัตโนมัติ ทำให้ระดับเสียงเปลี่ยนไปมาแม้พูดเท่าเดิม

## ไมโครโฟนไม่ทำงาน แก้ปัญหาอย่างไร

### เบราว์เซอร์ไม่ขอสิทธิ์ หรือเคยกดบล็อกไว้

กดไอคอนรูปกุญแจหรือไอคอนตั้งค่าข้างแถบที่อยู่ของเบราว์เซอร์ แล้วเปลี่ยนสิทธิ์ไมโครโฟนเป็น อนุญาต จากนั้นรีเฟรชหน้านี้ ถ้าเปิดลิงก์ในแอปอื่น เช่น Line หรือ Facebook ให้เปิดด้วย Chrome หรือ Safari แทน

### ระบบปฏิบัติการปิดกั้นไมโครโฟน

- **Windows** การตั้งค่า > ความเป็นส่วนตัวและความปลอดภัย > ไมโครโฟน แล้วเปิดการเข้าถึงไมโครโฟนและอนุญาตให้แอปเข้าถึง
- **macOS** การตั้งค่าระบบ > ความเป็นส่วนตัวและความปลอดภัย > ไมโครโฟน แล้วเปิดให้เบราว์เซอร์ที่ใช้
- **iPhone / iPad** การตั้งค่า > Safari > ไมโครโฟน
- **Android** การตั้งค่า > แอป > เบราว์เซอร์ที่ใช้ > สิทธิ์ > ไมโครโฟน

### มิเตอร์ไม่ขยับ

ตรวจว่าเลือกอุปกรณ์ถูกตัว ไม่ได้กดปิดเสียง (mute) ที่ตัวไมค์หรือปุ่มบนหูฟัง และไม่ได้ตั้งระดับ Input เป็นศูนย์ในการตั้งค่าเสียงของระบบ ลองเปลี่ยนพอร์ต USB หรือเสียบใหม่

### แอปอื่นใช้ไมค์อยู่

บางระบบให้แอปเดียวใช้ไมค์ได้ในเวลาเดียวกัน ให้ปิด Zoom, Teams, Discord, OBS หรือโปรแกรมอัดเสียง แล้วลองใหม่

### ไมค์บลูทูธมีหลายรายการหรือเสียงไม่ใส

หูฟังบลูทูธมักแสดงเป็นสองโหมด โหมดโทร (Hands-Free) มีไมค์ แต่ใช้อัตราสุ่มตัวอย่างต่ำ เสียงจึงแคบ ส่วนโหมดฟังเพลง (A2DP) คุณภาพสูงแต่ไม่มีไมค์ ถ้าต้องการเสียงพูดที่ใส ให้ใช้ไมค์แบบมีสายหรือไมค์ในตัวเครื่อง

### เสียงเบา เสียงแตก หรือมีเสียงฮัม

เสียงเบาให้ขยับเข้าใกล้ไมค์ 10 ถึง 15 ซม. หรือเพิ่มระดับ Input ในระบบ เสียงแตกให้ลดเกนหรือถอยห่างจากไมค์ เสียงฮัมให้ถอดที่ชาร์จ ย้ายสายไฟให้ห่างจากสายไมค์ หรือเปลี่ยนพอร์ต USB

## คำถามที่พบบ่อย

### ทดสอบไมโครโฟนออนไลน์ปลอดภัยหรือไม่

ปลอดภัย เสียงถูกประมวลผลในเบราว์เซอร์บนอุปกรณ์ของคุณเท่านั้น ไม่มีการส่งหรืออัปโหลดไปยังเซิร์ฟเวอร์ และไมค์จะหยุดทำงานเมื่อกดหยุดทดสอบหรือปิดแท็บ

### ถ้าเครื่องมือนี้ได้ยินเสียง จะใช้ใน Zoom, Google Meet, Teams หรือ Discord ได้หรือไม่

โดยทั่วไปได้ แสดงว่าไมค์และการอนุญาตของเบราว์เซอร์ทำงานปกติ แต่ในแต่ละแอปต้องเลือกไมโครโฟนตัวเดียวกันในการตั้งค่าเสียงของแอปนั้นด้วย

### ค่าเท่าไรถึงเรียกว่าดี

เสียงพูดควรมียอดสูงสุดราว -24 ถึง -6 dBFS ไม่เกิดเสียงแตก เสียงรบกวนพื้นหลังต่ำกว่า -45 dBFS และ SNR ตั้งแต่ 20 dB ขึ้นไป ดูตารางวิธีอ่านค่าด้านบนประกอบ

### ทำไมค่าเริ่มต้นจึงปิดการลดเสียงรบกวนและปรับเกนอัตโนมัติ

เพื่อให้เห็นสัญญาณดิบของไมค์และห้องจริง ถ้าเปิดฟังก์ชันเหล่านี้ ตัวเลขเสียงรบกวนและระดับเสียงจะถูกปรับแต่งจนไม่สะท้อนฮาร์ดแวร์ คุณสามารถเปิดเพื่อเปรียบเทียบกับที่แอปประชุมใช้ได้

### ใช้ทดสอบไมค์บนมือถือได้หรือไม่

ได้ รองรับ Chrome และ Safari บนมือถือและแท็บเล็ต ต้องเปิดหน้านี้ผ่าน HTTPS และอนุญาตสิทธิ์ไมโครโฟนให้เบราว์เซอร์

  function loop(now) {
    state.raf = requestAnimationFrame(loop);
    if (!state.anT) { return; }
    state.anT.getFloatTimeDomainData(state.tbuf);
    state.anF.getFloatFrequencyData(state.fbuf);
    var buf = state.tbuf, n = buf.length, sum = 0, peak = 0, clipN = 0, i, a;
    for (i = 0; i !== n; i++) {
      a = Math.abs(buf[i]);
      sum += a * a;
      if (a > peak) { peak = a; }
      if (a >= 0.99) { clipN++; }
    }
    var rmsDb = toDb(Math.sqrt(sum / n));
    var peakDb = toDb(peak);
    if (peakDb > state.maxPeak) { state.maxPeak = peakDb; }
    pushRing(state.hist, rmsDb, 300);
    pushRing(state.peaks, peakDb, 300);
    var isClip = clipN >= 2;
    if (isClip) {
      if (!state.wasClip) { state.clips++; }
      state.lastClipAt = now;
    }
    state.wasClip = isClip;
    if (peakDb >= state.hold) {
      state.hold = peakDb;
      state.holdAt = now;
    } else if (now - state.holdAt > 1000) {
      state.hold = Math.max(MIN_DB, state.hold - 0.6);
    }
    var clipping = 1500 > (now - state.lastClipAt);
    el.bar.style.width = (clamp((rmsDb + 60) / 60, 0, 1) * 100).toFixed(1) + '%';
    el.hold.style.left = (clamp((state.hold + 60) / 60, 0, 1) * 100).toFixed(1) + '%';
    if (clipping) { el.bar.className = 'mt-bar mt-bad'; }
    else if (peakDb > -6) { el.bar.className = 'mt-bar mt-warn'; }
    else { el.bar.className = 'mt-bar'; }
    el.clip.hidden = !clipping;
    humCheck(50, rmsDb);
    humCheck(60, rmsDb);
    drawWave(buf);
    drawSpec(state.fbuf);
    state.frame++;
    if (state.frame % 6 === 0) { refresh(now, rmsDb); }
  }

  function start() {

  }

  function startRecording() {
    if (!state.stream) { return; }
    if (state.recorder) { return; }
    var mime = pickMime();
    if (mime === null) {
      showError('เบราว์เซอร์นี้ไม่รองรับการอัดเสียง', ['ลองใช้ Chrome, Edge, Firefox หรือ Safari เวอร์ชันล่าสุด']);
      return;
    }
    var rec, chunks = [];
    try {
      rec = mime ? new MediaRecorder(state.stream, { mimeType: mime }) : new MediaRecorder(state.stream);
    } catch (e) {
      showError('เริ่มอัดเสียงไม่สำเร็จ', [String(e)]);
      return;
    }
    rec.ondataavailable = function (ev) {
      if (ev.data) { if (ev.data.size > 0) { chunks.push(ev.data); } }
    };
    rec.onstop = function () {
      if (chunks.length === 0) {
        el.recTime.textContent = 'ไม่มีข้อมูลเสียงที่อัดได้ ลองอัดใหม่อีกครั้ง';
        return;
      }
      var type = rec.mimeType ? rec.mimeType : 'audio/webm';
      var blob = new Blob(chunks, { type: type });
      var ext = 'webm';
      if (type.indexOf('mp4') !== -1) { ext = 'm4a'; } else if (type.indexOf('ogg') !== -1) { ext = 'ogg'; }
      addItem(URL.createObjectURL(blob), ext);
    };
    state.recorder = rec;
    rec.start();
    state.recStart = performance.now();
    el.rec.disabled = true;
    el.recStop.disabled = false;
    el.recTime.textContent = '● กำลังอัด 00:00 / 00:30';
    state.recTimer = setInterval(function () {
      var s = (performance.now() - state.recStart) / 1000;
      el.recTime.textContent = '● กำลังอัด ' + fmtTime(s) + ' / 00:30';
      if (s >= 30) { stopRecording(); }
    }, 200);
  }
