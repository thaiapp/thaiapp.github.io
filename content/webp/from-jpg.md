## วิธีใช้งานเครื่องมือแปลง JPG เป็น WebP

1. **เพิ่มรูปภาพ** ลากไฟล์ JPG หรือ PNG มาวางในกรอบด้านบน คลิกเพื่อเลือกไฟล์ หรือกด Ctrl/Cmd + V เพื่อวางรูปจากคลิปบอร์ด เลือกได้หลายไฟล์พร้อมกัน
2. **เลือกโหมดการบีบอัด** เลือก "ตามระดับคุณภาพ" เมื่ออยากควบคุมความคมชัดเอง หรือ "ตามขนาดไฟล์เป้าหมาย" เมื่อต้องการให้รูปมีขนาดไม่เกินค่าที่กำหนด เช่น 100 KB
3. **ตั้งค่าคุณภาพ** เลื่อนแถบคุณภาพหรือกดปุ่มสำเร็จรูป สำหรับรูปถ่ายทั่วไป ค่า 75–85 มักให้ผลดีที่สุดเมื่อเทียบระหว่างขนาดกับความคมชัด
4. **จำกัดความกว้าง (ถ้าต้องการ)** เลือกความกว้างสูงสุด เช่น 1920 px สำหรับภาพประกอบเว็บไซต์ รูปที่เล็กกว่าค่านี้จะไม่ถูกขยาย
5. **ตั้งชื่อไฟล์ (ถ้าต้องการ)** พิมพ์รูปแบบชื่อ เช่น `[name]-web` เพื่อให้ไฟล์ `photo.jpg` กลายเป็น `photo-web.webp`
6. **ตรวจผลลัพธ์** แต่ละรูปจะแสดงขนาดก่อนและหลังแปลง กดปุ่ม "เปรียบเทียบ" เพื่อเลื่อนดูภาพต้นฉบับกับ WebP เทียบกัน
7. **ดาวน์โหลด** กด "ดาวน์โหลด" ทีละรูป หรือ "ดาวน์โหลดทั้งหมดเป็น ZIP" เมื่อแปลงหลายไฟล์
8. **ปรับแล้วแปลงใหม่** หากเปลี่ยนค่าตั้ง ให้กด "ใช้ค่าตั้งใหม่กับทุกไฟล์" โดยไม่ต้องเลือกไฟล์ซ้ำ
9. **นำไปใช้บนเว็บไซต์** เปิดกล่อง "โค้ด HTML สำหรับใช้รูป WebP บนเว็บไซต์" แล้วคัดลอกแท็ก `<picture>` ที่พร้อมใช้

## อธิบายคำศัพท์และตัวเลือกในเครื่องมือ

| คำศัพท์ | ความหมายโดยย่อ |
|---|---|
| WebP | รูปแบบไฟล์ภาพที่พัฒนาโดย Google ไฟล์เล็กกว่า JPG ราว 25–35% ในระดับความคมชัดใกล้เคียงกัน และรองรับพื้นหลังโปร่งใส |
| JPG / JPEG | รูปแบบภาพถ่ายที่ใช้กันแพร่หลายที่สุด บีบอัดแบบสูญเสียข้อมูล ไม่รองรับพื้นหลังโปร่งใส |
| PNG | รูปแบบภาพที่คงรายละเอียดครบและรองรับพื้นหลังโปร่งใส แต่ไฟล์มักใหญ่ |
| การบีบอัดแบบ Lossy | ตัดรายละเอียดที่ตาเห็นยากออกเพื่อให้ไฟล์เล็กลง ยิ่งบีบมาก ไฟล์ยิ่งเล็กแต่ภาพยิ่งหยาบ |
| Lossless | การบีบอัดที่ไม่ทิ้งรายละเอียดภาพเลย ไฟล์จึงใหญ่กว่า ที่คุณภาพ 100 บางเบราว์เซอร์ (เช่น Chrome) จะเข้ารหัสแบบนี้ |
| คุณภาพ (Quality) | ค่า 1–100 ที่กำหนดระดับการบีบอัด ค่าสูงภาพคมแต่ไฟล์ใหญ่ ค่าต่ำไฟล์เล็กแต่ภาพอาจเป็นรอยบล็อก |
| ขนาดไฟล์เป้าหมาย (Target size) | เครื่องมือหาคุณภาพที่สูงที่สุดซึ่งทำให้ไฟล์ไม่เกินขนาดที่ตั้งไว้ หากยังใหญ่เกิน จะลดความกว้างของภาพลงทีละน้อยให้อัตโนมัติ |
| ความกว้างสูงสุด (Max width) | ย่อภาพที่กว้างเกินค่านี้ลง โดยรักษาสัดส่วนเดิม ภาพที่เล็กกว่าจะไม่ถูกขยาย |
| รูปแบบชื่อไฟล์ | ข้อความกำหนดชื่อไฟล์ผลลัพธ์ โดย `[name]` จะถูกแทนด้วยชื่อไฟล์เดิม (ไม่รวมนามสกุล) |
| EXIF | ข้อมูลที่ฝังในรูปถ่าย เช่น วันเวลา รุ่นกล้อง และพิกัด GPS ไฟล์ที่แปลงจากเครื่องมือนี้จะไม่มี EXIF ช่วยปกป้องความเป็นส่วนตัวและลดขนาดไฟล์ โดยภาพยังหมุนตามทิศทางถ่ายให้ถูกต้อง |
| Batch (แปลงหลายไฟล์) | การแปลงรูปจำนวนมากในครั้งเดียวด้วยค่าตั้งเดียวกัน |
| ZIP | ไฟล์บีบอัดที่รวมรูปที่แปลงแล้วทั้งหมดไว้ในไฟล์เดียว สะดวกต่อการดาวน์โหลด |
| ก่อน/หลัง (Before / After) | ตัวเลื่อนเปรียบเทียบภาพต้นฉบับกับผลลัพธ์ เพื่อดูว่าคุณภาพยังยอมรับได้หรือไม่ |
| พื้นหลังโปร่งใส (Alpha) | ส่วนของภาพที่มองทะลุเห็นพื้นหลังด้านหลัง ภาพ PNG ที่มีส่วนโปร่งใสจะยังโปร่งใสเมื่อแปลงเป็น WebP |
| ประมวลผลในเครื่อง (Client-side) | การแปลงเกิดในเบราว์เซอร์ของคุณเอง รูปภาพไม่ถูกส่งออกไปยังเซิร์ฟเวอร์ใด ๆ |
| Core Web Vitals / LCP | ตัวชี้วัดความเร็วเว็บของ Google โดย LCP คือเวลาที่เนื้อหาหลักของหน้าเว็บ (มักเป็นรูปภาพ) แสดงผลเสร็จ รูปที่เล็กลงช่วยให้ค่านี้ดีขึ้น |
| แท็ก `<picture>` | แท็ก HTML ที่ให้เบราว์เซอร์เลือกรูป WebP ก่อน และถอยกลับไปใช้ JPG เดิมเมื่อไม่รองรับ |

## ทำไมต้องแปลง JPG เป็น WebP

รูปภาพมักเป็นส่วนที่มีขนาดใหญ่ที่สุดของหน้าเว็บ การเปลี่ยนจาก JPG เป็น WebP ช่วยให้หน้าเว็บโหลดเร็วขึ้น ประหยัดแบนด์วิดท์ และช่วยปรับคะแนนความเร็วเว็บไซต์ รวมถึงตัวชี้วัด LCP ของ Core Web Vitals นอกจากนี้ยังประหยัดพื้นที่จัดเก็บบนเซิร์ฟเวอร์และอุปกรณ์ โดยภาพยังคมชัดใกล้เคียงต้นฉบับเมื่อเลือกคุณภาพเหมาะสม

## เปรียบเทียบ JPG, PNG, WebP และ AVIF

| หัวข้อ | JPG | PNG | WebP | AVIF |
|---|---|---|---|---|
| การบีบอัด | Lossy | Lossless | Lossy และ Lossless | Lossy และ Lossless |
| พื้นหลังโปร่งใส | ไม่รองรับ | รองรับ | รองรับ | รองรับ |
| ขนาดไฟล์ | ปานกลาง | ใหญ่ | เล็กกว่า JPG | มักเล็กที่สุด |
| การรองรับเบราว์เซอร์ | ทุกเบราว์เซอร์ | ทุกเบราว์เซอร์ | เบราว์เซอร์หลักทุกตัว | เบราว์เซอร์รุ่นใหม่ส่วนใหญ่ |
| เหมาะกับ | รูปถ่ายทั่วไป | โลโก้ ภาพกราฟิก | รูปบนเว็บทุกประเภท | เว็บที่ต้องการไฟล์เล็กสุด |

## วิธีนำรูป WebP ไปใช้บนเว็บไซต์

อัปโหลดไฟล์ WebP ที่ได้ไปไว้คู่กับไฟล์เดิม แล้วใช้แท็ก `<picture>` เพื่อให้เบราว์เซอร์ที่ไม่รองรับยังแสดงรูป JPG ได้ตามปกติ ระบุ `width` และ `height` ทุกครั้งเพื่อป้องกันหน้าเว็บกระตุก และใช้ `loading="lazy"` กับรูปที่อยู่ต่ำกว่าหน้าจอแรก

```html
<picture>
  <source srcset="photo.webp" type="image/webp">
  <img src="photo.jpg" alt="คำอธิบายรูปภาพ" width="1200" height="800" loading="lazy" decoding="async">
</picture>
```

## คำถามที่พบบ่อย (FAQ)

### แปลง JPG เป็น WebP แล้วคุณภาพลดลงไหม?

หากตั้งคุณภาพประมาณ 75–85 ความแตกต่างมักแทบมองไม่เห็นในรูปถ่ายทั่วไป แต่ไฟล์จะเล็กลงอย่างชัดเจน ใช้ปุ่ม "เปรียบเทียบ" เพื่อตรวจก่อนนำไปใช้จริง

### ไฟล์ของฉันถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่?

ไม่ การแปลงทั้งหมดทำงานในเบราว์เซอร์ของคุณ รูปภาพไม่ออกจากอุปกรณ์ จึงปลอดภัยสำหรับรูปส่วนตัวหรือเอกสารสำคัญ

### จะย่อรูปให้ไม่เกิน 100 KB ได้อย่างไร?

เลือกโหมด "ตามขนาดไฟล์เป้าหมาย" แล้วกรอก 100 เครื่องมือจะปรับคุณภาพ และลดความกว้างของภาพให้เองหากจำเป็น

### ควรตั้งค่าคุณภาพเท่าไร?

รูปถ่ายบนเว็บไซต์ทั่วไปแนะนำ 75–85 ภาพที่ต้องการความละเอียดสูงใช้ 90 ขึ้นไป และหากต้องการไฟล์เล็กมากให้ใช้ 60–70 แล้วตรวจด้วยตัวเลื่อนเปรียบเทียบ

### แปลงได้ครั้งละกี่ไฟล์?

ไม่จำกัดจำนวนไฟล์ แต่ขึ้นอยู่กับหน่วยความจำของอุปกรณ์ หากรูปมีขนาดใหญ่มากหรือมีจำนวนมาก ควรแบ่งแปลงเป็นชุดย่อย

### ใช้บนมือถือได้ไหม?

ได้ หากเบราว์เซอร์รองรับการสร้างไฟล์ WebP เช่น Chrome หรือ Edge บางเบราว์เซอร์ เช่น Safari บางเวอร์ชัน อาจสร้างไฟล์ WebP ไม่ได้ ระบบจะแจ้งเตือนในหน้านี้

### แปลง WebP กลับเป็น JPG ได้ไหม?

ได้ ใช้เครื่องมือ [แปลง WebP เป็น JPG](/webp/to-jpg/) อย่างไรก็ตาม การแปลงกลับไปกลับมาหลายครั้งทำให้คุณภาพลดลงสะสม ควรเก็บไฟล์ต้นฉบับไว้เสมอ
