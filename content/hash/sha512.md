SHA-512 เป็นอัลกอริทึมแฮชในตระกูล SHA-2 ที่แปลงข้อความความยาวเท่าใดก็ได้ให้เป็นค่าสรุปขนาดคงที่ 512 บิต หรือเลขฐานสิบหก 128 ตัวอักษร ข้อความเดิมเปลี่ยนเพียงตัวอักษรเดียว ผลลัพธ์ก็จะต่างไปโดยสิ้นเชิง และไม่สามารถย้อนกลับไปหาข้อความต้นฉบับได้

  function iroot(n, k) {
    var kb = BigInt(k);
    var x = 2n ** BigInt(Math.ceil(n.toString(2).length / k) + 1);
    while (true) {
      var y = ((kb - 1n) * x + n / (x ** (kb - 1n))) / kb;
      if (y >= x) { return x; }

  function primes(count) {
    var list = [];

        if (list[i] * list[i] > c) { break; }

    return ((x >> n) | ((x * (2n ** (64n - n))) & M)) & M;
  }

    initConstants();
    var arr = Array.from(data);
    var bitLen = BigInt(arr.length) * 8n;

## วิธีใช้งานเครื่องมือ

1. พิมพ์หรือวางข้อความที่ต้องการลงในช่อง "ข้อความที่ต้องการแฮช"
2. ค่าแฮช SHA-512 จะแสดงทันทีในกรอบด้านล่าง โดยไม่ต้องกดปุ่มสร้าง และจะอัปเดตทุกครั้งที่แก้ไขข้อความ
3. ดูขนาดข้อความเป็นไบต์ได้ที่ด้านซ้ายของแถบสถานะ (ข้อความภาษาไทยหนึ่งตัวอักษรใช้ 3 ไบต์ใน UTF-8)
4. กดปุ่ม "คัดลอก" เพื่อคัดลอกค่าแฮชไปใช้งาน เช่น เทียบกับค่าที่ได้จากระบบอื่น
5. กดปุ่ม "ล้าง" เพื่อลบข้อความและเริ่มใหม่

ข้อความที่ป้อนจะถูกประมวลผลในเบราว์เซอร์ของคุณเท่านั้น ไม่มีการส่งข้อมูลไปยังเซิร์ฟเวอร์

## คำอธิบายศัพท์

- **แฮช (Hash)**: ค่าสรุปที่ได้จากการนำข้อมูลเข้าฟังก์ชันทางเดียว ใช้เป็น "ลายนิ้วมือ" ของข้อมูล ข้อมูลเดียวกันได้ค่าเดิมเสมอ
- **ฟังก์ชันแฮช (Hash Function)**: สูตรคำนวณที่แปลงข้อมูลทุกขนาดให้เป็นค่าแฮชขนาดคงที่ เช่น MD5, SHA-1, SHA-256, SHA-512
- **SHA-2**: ตระกูลฟังก์ชันแฮชที่พัฒนาโดย NSA ประกอบด้วย SHA-224, SHA-256, SHA-384 และ SHA-512
- **SHA-512**: สมาชิกของ SHA-2 ที่ให้ผลลัพธ์ 512 บิต ภายในใช้การคำนวณแบบ 64 บิต จึงทำงานได้ดีบน CPU 64 บิต
- **512 บิต**: ขนาดของค่าแฮช เท่ากับ 64 ไบต์ เมื่อเขียนเป็นเลขฐานสิบหกจะได้ 128 ตัวอักษร
- **เลขฐานสิบหก (Hexadecimal)**: ระบบเลขที่ใช้ 0-9 และ a-f ใช้แสดงค่าไบนารีให้อ่านง่าย โดย 1 ไบต์แทนด้วย 2 ตัวอักษร
- **ไบต์ (Byte)**: หน่วยข้อมูลพื้นฐาน เท่ากับ 8 บิต เครื่องมือนี้แสดงจำนวนไบต์ของข้อความหลังแปลงเป็น UTF-8
- **UTF-8**: รูปแบบการเข้ารหัสตัวอักษรที่ใช้แปลงข้อความเป็นไบต์ก่อนนำไปแฮช ข้อความเดียวกันที่เข้ารหัสต่างกันจะได้แฮชต่างกัน
- **Checksum**: ค่าตรวจสอบความสมบูรณ์ของข้อมูล ใช้ยืนยันว่าไฟล์หรือข้อความไม่ถูกแก้ไขระหว่างส่งต่อ
- **HMAC**: วิธีสร้างรหัสยืนยันข้อความโดยใช้ฟังก์ชันแฮชร่วมกับกุญแจลับ เช่น HMAC-SHA512
- **PBKDF2**: อัลกอริทึมสร้างกุญแจจากรหัสผ่านโดยแฮชซ้ำหลายรอบ เพื่อให้การเดาสุ่มทำได้ยากขึ้น
- **Salt**: ข้อมูลสุ่มที่เติมเข้าไปก่อนแฮชรหัสผ่าน ช่วยป้องกันการโจมตีด้วยตารางแฮชที่คำนวณไว้ล่วงหน้า
- **Collision (การชนกัน)**: เหตุการณ์ที่ข้อมูลสองชุดต่างกันให้ค่าแฮชเดียวกัน ฟังก์ชันแฮชที่ดีต้องหาคู่ที่ชนกันได้ยากมาก

## SHA-512 เหมาะกับงานแบบไหน

SHA-512 เหมาะเมื่อต้องการระดับความปลอดภัยที่เผื่อไว้มากขึ้นโดยยังอยู่ในตระกูล SHA-2 เช่น ลายเซ็นดิจิทัลที่ต้องใช้งานยาวนาน กุญแจ HMAC หรือการสร้างกุญแจด้วย PBKDF2-HMAC-SHA512 ส่วนงานทั่วไป SHA-256 ซึ่งสั้นกว่าก็ให้ความปลอดภัยที่ยอมรับได้เช่นกัน

ข้อควรระวัง: การแฮชด้วย SHA-512 เพียงอย่างเดียวไม่เหมาะสำหรับเก็บรหัสผ่านโดยตรง ควรใช้อัลกอริทึมเฉพาะทางที่ช้าโดยตั้งใจ เช่น Argon2, bcrypt หรือ PBKDF2 ร่วมกับ Salt
